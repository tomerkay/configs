# Pushes and MRs are mine

**Finishing a branch never ends in an offer to push or to open an MR,
and a push is never yours to run.** Never suggest, offer or prompt a
`git push` - not as a next step, not as a `! git push` to paste, not as
"ready to push". When I ask for a push, in whatever words, "I allow you
this time" included, print the exact command as `! git push ...`
straight away and attempt nothing else: no policy check, no remote
lookup, no other route to the remote - only the local reads that build
the command. An MR or PR is opened only when I ask for one. Neither is
a "next step" you suggest, and neither is an MR title or description:
never write, draft, offer or ask about either unless I ask for it
myself. When something only a description would carry matters (a
metric whose meaning changed, a rule a change retires), tell me in
chat.
