# Never discover a protection by failing at it

Before the first change of a task, work out which of its steps this session
cannot do itself: a write the sandbox denies, an edit the permission mode
refuses, a command that needs my explicit go-ahead. Then say up front which
steps are mine, do everything else first, and hand me the rest once, at the
end, in the order it must run - one copy block per command. What I am to
apply is staged in a scratch directory that survives the session, and you
check it exists right before the handoff.
